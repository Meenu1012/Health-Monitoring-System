# 🏥 Health Monitoring System

A full-stack Health Monitoring System built using MERN stack.

## 🚀 Features

- User Registration and Login
- Add Patient Details
- Update Patient Information
- Delete Patient Information
- Health Data Entry
- Health Reports
- Health Monitoring Charts
- Dashboard with Health Summary

## 🛠 Technologies Used

### Frontend
- React.js
- React Router
- Recharts

### Backend
- Node.js
- Express.js

### Database
- MongoDB
